# 学药方（FormulaScholar）

基于《中国药典》2025 与经典方剂学的处方审查与学习助手。

> 定位：专业数据基础之上的学习教育工具，非专业医疗审核系统。

## 功能

| 模式 | 说明 | 示例 |
|------|------|------|
| **审查** | 上传处方，七维审查（配伍禁忌/剂量/组方/炮制/风险） | "审核这个方子" |
| **浏览** | 按 21 章治法分类浏览 198 首经典正方 | "列出所有补益剂" |
| **搜索** | 按方名/主治/药材/功效多维检索 | "治咳嗽的方有哪些" |
| **对比** | 两方并排对比组成、功效、主治差异 | "比较麻黄汤和桂枝汤" |
| **学习** | 方歌背诵、演化链追溯、药对分析 | "麻黄汤的方歌" |

## 数据规模

| 数据 | 数量 | 来源 |
|------|------|------|
| 药材 | 617 味 | 《中国药典》2025 年版一部 |


## 工作原理

### 审查模式 — 七维框架

```
1. 药材识别层 → 正名/别名匹配 + 剂量提取 + 炮制品识别
2. 配伍禁忌层 → 十八反/十九畏 + 妊娠/儿童/老年/体质/病情禁忌
3. 剂量审核层 → 每味药 vs 药典范围 + 毒性药特别关注
4. 组方结构层 → 经典方溯源 + 君臣佐使推断 + 架构图
5. 炮制合理性层 → 炮制品与治法匹配度
6. 风险综合层 → 🔴高风险 / 🟡中风险 / 🟢低风险
7. 一句话总结 → 方剂溯源 + 核心功效 + 关键提示
```

### 搜索模式 — 多维索引

- 方名匹配（精确 + 模糊）
- 主治关键词检索
- 药材反向查方
- 功效匹配

### 学习模式 — 知识关联

- 方歌展示 + 逐句解释
- 演化链：基础方 → 本方 → 衍生方
- 药对配伍机理分析 + 经典方实例
