# 深度问题拆解引擎（DPDE）

通用问题拆解框架——穿透表象、构建问题树、评估价值、遴选最小有效集、系统推演综合效应。

## 核心哲学

用户的问题常常是**症状**，不是**病灶**。回答一个错误的问题，越精准，越危险。DPDE 的目标不是"回答用户"，而是**帮用户找到那个值得回答的真问题**，并把它拆成一组可执行、高杠杆、有系统视野的子问题。

## 五层引擎

```
第一层：审计（Audit）    → 穿透表象，找到「真问题」
第二层：拆解（Decompose） → 多维 MECE，构建问题树
第三层：评估（Evaluate）  → 测 IV/LE 杠杆，定策略象限
第四层：遴选（Select）    → 选最小有效集（MEQS），画推理路线
第五层：综合（Synthesize） → 系统推演正负效应 + 事前析误
```

每层产出为下一层的必要输入。**铁律：不可跳过任何一层。**

## 快速开始

```
# 用 DPDE 拆解任何复杂问题
> /deep-decompose
> DPDE: 甲领导安排我去做某件事，但乙领导老是找理由让我去干另外的事情...

# 或者自然语言
> 帮我系统拆解这个问题：[你的问题]
> 做一个深度问题拆解：[你的问题]
```

DPDE 会将你的问题转化为一份结构化报告（主报告 ≤300 行 + 完整附件），包含：
- 真问题陈述（一句话，比原问题更锋利）
- 完整问题树（多维 MECE 拆解）
- IV×LE 策略矩阵（哪些子问题是王牌？哪些可以舍弃？）
- 最小有效问题集 + 推理路线图
- 正/负效应链 + 二阶效应 + 事前析误
- 行动建议表（立即做/短期做/长期做/避免做）

## 设计原则

- **不是回答问题，是重新定义问题** —— 第一层审计的目标是让真问题与用户原问题"明显不同"
- **不是打分，是测杠杆** —— 第三层用 2×2 策略矩阵而非线性加权，找到"解决一个、解放一片"的王牌
- **不是选前5个，是选最小有效集** —— 第四层按覆盖面和杠杆效应选 3–7 个，合起来覆盖真问题 80%+
- **不是建议，是系统推演** —— 第五层强制做副作用扫描 + 二阶效应 + 事前析误，避免短视建议

## 安全边界

入口守卫包含安全红线检查。涉及违法违纪、不道德行为、可能导致他人伤害、或涉及自伤/严重心理危机的问题将拒绝拆解。

## 免责声明

本 Skill 是思维框架的产物，不是专业建议。所有分析结论均基于用户提供的信息和通用方法论推演，实际情况可能有未被捕获的关键变量。请将输出报告视为决策的「思考辅助」而非「最终答案」。如涉及法律、医疗、金融投资等领域，请咨询相关专业人士。
