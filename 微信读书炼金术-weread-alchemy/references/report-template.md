# 读书笔记总结与反思报告 — 输出格式模板

本文件是 `weread-alchemy` skill 的最终报告格式参考。Agent 按照此结构生成报告，`{占位符}` 用实际数据替换。

---

## 报告整体结构

1. **头部卡片** — 书籍信息 + 阅读档案
2. **一、笔记与划线清单** — 按章节排列 → 全书点评 → 笔记质量评价（雷达/柱形图）→ 核心发现
3. **二、你的笔记 vs 大众热门笔记** — 对比分析
4. **三、你的心智模式** — 可迁移规则提炼
5. **四、你最独特的发现** — 阅读模式/独特视角
6. **五、努力提升的方向** — 行动建议
7. **六、跨书对比** — （如有历史数据）
8. **七、一句话总结** — 核心洞察

## 深度链接规范

在展示每条笔记时，附加微信读书深度链接方便跳转：

```
[📖 跳转原文](weread://bestbookmark?bookId={bookId}&chapterUid={chapterUid}&rangeStart={rangeStart}&rangeEnd={rangeEnd})
```

对于划线笔记：使用 `bookmarklist` 中的 `chapterUid`、`rangeStart`、`rangeEnd`。
对于想法：使用其关联划线的范围信息；若无关联划线（纯想法），可省略深度链接。

---

## 数据展示规范

1. **时间戳**：所有 Unix 时间戳转为 `YYYY-MM-DD` 格式。
2. **阅读时长**：秒转为"X小时Y分钟"格式。
3. **评分展示**：`newRating` 字段为千分制评分（如 735 = 7.35分），展示时转为十分制（73.5%）或保持原始格式说明。
4. **阅后评价**：`star=100` → "推荐"，`star=60` → "一般"，`star=20` → "不行"。
5. **排序**：笔记与划线按章节顺序排列，同章节内按 `rangeStart` 升序。
6. **隐私保护**：报告中仅展示用户本人笔记，不向第三方泄露。
