# 笔记质量评分标准 — 五维度 2–5 分制（微信读书批注专用）

本文件是 `weread-alchemy` skill 的评分标准。Agent 对每条想法/书评进行五维度定性评价时，严格按此标准打分。

---

## 评分原则

- **评分对象**：微信读书的划线批注（想法），通常为 1–3 句话，偶有 1–2 小段。
- **评分方式**：Agent 对照原文上下文，按本评分标准对每条想法进行语义分析和打分，评分 JSON 通过管道或 `--scores` 文件传给 `compute_quality.py` 完成低分补偿和格式组装，存入 `notes_scored.json`。
- **总分计算**：所有想法与书评在各维度的平均分 = 该书的维度评分。再取五维均值 = 书籍笔记质量总分。
- **本质认知**：批注是阅读时的即兴思维火花，短小、碎片、以共鸣为主是自然特征，不是缺陷。**一条精妙的短批注远胜一段平庸的长文。**
- **评分范围**：2–5 分。2 分为基准分（最低），缺失维度默认补 2 分。
- **低分补偿**：单维度得分 < 3 分时，自动加 0.5 分，以 3 分为上限（即补偿后不超过 3 分）。
- **加粗标记**：单条想法/书评的五维均分 ≥ 3.5 时，报告中本条加粗展示。

---

## 维度一：方法论 (Methodology)

> 能看出原文中的做事方法或思维套路吗？哪怕只是用一句话点出来。

| 分 | 判定 |
|----|------|
| **2** | 理解了原文想表达的思维或行动方法，用自己的话重新说了一遍，或表达了简单感悟。 |
| **3** | 识别出一个可复用的思维套路或行为模式，并用一句话概括出来。如"这就是错位竞争"。 |
| **4** | 给这个套路命了名，或做了简单结构化（如"分三步""两个条件"）。 |
| **5** | 提炼出一个可直接拿来用的思维工具，命名清晰、边界明确——别人看了也能用。 |

> **注意**：2 分是基准分——正确理解原文并用自己的话表达了就是 2 分。一句话说清楚一个套路，就是 3 分起评。

---

## 维度二：批判性 (Critical Thinking)

> 有自己的判断吗？不一定是反驳，补充、限定、换个角度都算。

| 分 | 判定 |
|----|------|
| **2** | 不是完全认同。 |
| **3** | 指出原文的限定条件（"但XX情况下不适用"），或结合自身经验与知识做了补充或延伸。 |
| **4** | 有理由地质疑了原文的某个观点或逻辑，或提出了不同看法，或从不同角度阐释了同一问题。 |
| **5** | 一针见血地指出了原文的深层问题或提出了有洞察力的替代视角。 |

> **注意**：对原文的延伸、补充、限定、修正都算批判，不一定是"否定"，就是3分起评。

---

## 维度三：创新性 (Innovation/Creativity)

> 有超出原文的新东西吗？跨领域联想、新颖比喻、深度洞察、独特解读都算。

| 分 | 判定 |
|----|------|
| **2** | 做了一个跨领域的简单类比或联想（"这让我想起XX"）。 |
| **3** | 类比或联想有启发性，让人对原文产生了新的理解，或对原文进行了更深层次的挖掘。 |
| **4** | 用自己独特的知识框架重新诠释了原文，视角新颖且自洽，或者对原文进行了深度洞察。 |
| **5** | 产生了一个让人"哇"的洞见——换个角度看，原文完全不一样了。 |

> **注意**：一条几十字的跨界联想可以远超几百字的复述。跨学科联通是重要加分项。

---

## 维度四：审美性 (Aesthetics)

> ① 感知到了原文语言/结构的妙处吗？② 自己的笔记写得漂亮吗？取较高分。

| 分 | 判定 |
|----|------|
| **2** | 表达通顺、逻辑清楚，是一句合格的日常表达。 |
| **3** | 对原文的语言特点有具体点评，或笔记本身有节奏、有对仗、有点味道。 |
| **4** | 笔记是一句可以摘出来的"金句"——精炼、有力、有风格。 |
| **5** | 笔记让人想划线——用词精准、意象独特，寥寥数字穿透本质。 |

> **注意**：双层评分——取"对原文的审美感知"和"笔记本身的文字美"中的较高分。对非文学类书籍，语言清晰度、结构逻辑性也是审美。

---

## 维度五：行动性 (Actionability)

> 能让人想做点什么吗？哪怕只是一个明确的方向。

| 分 | 判定 |
|----|------|
| **2** | 有模糊的意愿或启发（"值得学习""以后要注意"）。 |
| **3** | 有一个明确的行动方向或可执行的动作描述（"下次可以试试XX""每天花30分钟做XX"）。 |
| **4** | 行动描述具体——做什么、怎么做、什么时候做，都有了。 |
| **5** | 不仅说清了行动，还提到了如何检验效果或如何持续迭代。 |

> **注意**：行动性考察的是"有没有指向行为"，不是"有没有列出完整计划"。一句"下周技术评审时试用"就是 3 分。

## 评分示例

### 示例 1：高质量批注（均分 3.0，无补偿）

> **原文**：黄仁勋倡导"光速"调度——设想理想情况下任务完成的最快速度。
> **想法**：不是要求实际达到光速，而是用理论极限暴露执行的浪费。和物理学的"理想实验"同构。

- 方法论 4：提炼并命名了"光速思维"，还做了跨域类比锚定。
- 批判性 2：延伸理解，未质疑原文。
- 创新性 4：跨领域连接到物理学"理想实验"，新颖恰当。
- 审美性 3：表达凝练，"同构"一词精准。
- 行动性 2：有启发但无具体行动。
- 均分：3.0（无维度 <3，不触发补偿）

### 示例 2：中等质量批注（Agent 均分 2.4 → 补偿后 2.8）

> **原文**：我的动力源自好奇心。我从未受过经济收益的驱动。
> **想法**：好奇心是最大的动力，最好的老师，也是最大幸福的源泉。

- 方法论 2→2.5：用自己的话概括并做了三重延伸。（<3，+0.5）
- 批判性 2→2.5：延伸了自己的理解。（<3，+0.5）
- 创新性 2→2.5：三重功能的归纳不算新颖。（<3，+0.5）
- 审美性 4：排比句式，节奏好，金句潜质。
- 行动性 2→2.5：有启发。（<3，+0.5）
- Agent 均分：(2+2+2+4+2)/5 = 2.4 → 补偿后：(2.5+2.5+2.5+4+2.5)/5 = **2.8**

### 示例 3：低质量批注（Agent 均分 2.0 → 补偿后 2.5）

> **原文**：数学的真假并不是人的意志所能改变的。
> **想法**：说得太对了。

- 方法论 2→2.5：简单表达了认同。（地板 2，<3 补偿 +0.5）
- 批判性 2→2.5：完全跟着原文走。（地板 2，<3 补偿 +0.5）
- 创新性 2→2.5：纯复述。（地板 2，<3 补偿 +0.5）
- 审美性 2→2.5：无文字讲究。（地板 2，<3 补偿 +0.5）
- 行动性 2→2.5：无行动关联。（地板 2，<3 补偿 +0.5）
- 补偿后均分：**2.5**

## 评分流程提醒

Agent 执行评分时，应遵循：
1. **身份校准**：你评的是手机上的即兴读书批注，不是学术论文。短不等于差，共鸣不等于盲从。
2. **先读后评**：阅读想法/书评的全文，理解其在章节语境中的位置。
3. **逐维打分**：依次用五个维度的标准衡量，不要跳维度。
4. **宽严适度**：2 分是基准分（最低），正确理解原文并表达了就是 2 分。3 分 = 是一条好批注，有独立见解或个人风格。4 分 = 是优秀批注，有提炼或金句。5 分 = 是极少数让人"哇"的批注。保留小数点后一位（四舍五入）。
5. **质量优先于数量**：一条精妙的短批注可以远高于一大段复述。
6. **低分补偿规则**：Agent 评分后，`compute_quality.py` 自动对低于 3 分的维度加 0.5 分（以 3 分为上限）。即 2.0→2.5、2.5→3.0、3.0+不变。Agent 无需自行补偿，按本标准逐维打分即可。
7. **评分传递**：评分由 Agent 按本评分标准完成，通过管道或文件传给 `compute_quality.py` 进行低分补偿，组装后存入 `notes_scored.json`。
