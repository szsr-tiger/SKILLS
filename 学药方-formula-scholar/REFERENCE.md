# 学药方 · 参考手册

本文件为 SKILL.md 的补充文档，包含七维审查框架详解、毒性分级表、禁忌分级表、字段说明和别名映射表。仅在审查模式激活且需要详细规则时加载。

## 一、七维审查框架详解

### 1.1 药材识别层

**操作流程**：
1. 从处方输入中解析每味药
2. 正名匹配 → `herbs.json` 的 `name` 字段
3. 别名匹配 → `herbs.json` 的 `aliases` 字段
4. 剂量提取 → 数字 + 单位（g/克/两/钱/分）
5. 炮制品识别 → 前缀（生/炙/炒/焦/煅/酒/醋/盐/蜜/姜/法/清/麸/土/砂/蛤/滑石/朱/制/蒸/煨/霜/炭/曲/芽）

**未匹配药材处理**：
- 标注"未识别"并提示用户确认
- 尝试模糊匹配（字符相似度 ≥ 70%）
- 降级策略：能匹配多少算多少，不阻塞后续审查

**输出字段**：药材名、剂量(g)、炮制品、四气、五味、归经、药典剂量范围、剂量判定状态

#### 儿童禁忌

特别关注含毒性成分的药材：
- 苦杏仁（含苦杏仁苷 → 氢氰酸）
- 白果（含氢氰酸）
- 细辛（含挥发油，中枢影响）
- 附子（有毒成分）
- 儿童剂量一般减半或按体重计算

#### 体质禁忌（从 herbs.json 的 contraindications.体质 提取）

- **阴虚体质**：忌温燥药（附子、肉桂、干姜等）
- **阳虚体质**：忌寒凉药（石膏、知母、黄连等）
- **气虚体质**：忌破气药（枳实、青皮等）
- **血虚体质**：忌破血药（三棱、莪术等）
- **中满者**：忌甘草（甘能助湿）

#### 病情禁忌（从 herbs.json 的 contraindications.病情 提取）

- **出血证**：忌活血化瘀药、破血药
- **表证未解**：忌收敛固涩药
- **实热证**：忌温补药
- **虚寒证**：忌攻下药

### 1.3 剂量审核层

#### 判定标准

| 状态 | 条件 | 标识 |
|------|------|------|
| 偏低 | 剂量 < 药典下限 × 0.5 | ⬇️ |
| 正常 | 药典下限 ≤ 剂量 ≤ 药典上限 | ✅ |
| 偏大 | 药典上限 < 剂量 ≤ 药典上限 × 1.5 | ⚠️ |
| 超量 | 剂量 > 药典上限 × 1.5 | 🔴 |
| 毒性药超量 | 毒性级别 ≥ 1 且 剂量 > 药典上限 | 🔴🔴 |

#### 毒性分级（0–3 级）

| 级别 | 说明 | 药材数 | 示例 |
|------|------|--------|------|
| 0 | 无毒 | 536 味 | 甘草、当归、黄芪 |
| 1 | 有小毒 | 34 味 | 苦杏仁、细辛、吴茱萸、重楼 |
| 2 | 有毒 | 38 味 | 半夏、附子、川乌、草乌、天南星、马钱子 |
| 3 | 有大毒 | 9 味 | 斑蝥、砒石、水银、轻粉、雄黄 |

#### 毒性药特殊规则

- 0 级：无特别限制
- 1 级：必须在药典范围内，超量需 🔴 警示
- 2 级：严格控制，超上限 1.2 倍即 🔴 警示
- 3 级：严格按药典剂量，任何超量均 🔴🔴 严重警示

#### 全方总剂量

全方总剂量（所有药味 g 数之和）的一般参考：
- < 50g：轻剂
- 50–150g：常用量
- 150–300g：重剂
- > 300g：需提醒注意

### 1.4 组方结构层

#### 基础方匹配算法

1. **精确匹配**：用户方药材集合 = 经典方药材集合 → 直接溯源为"即XX方"
2. **子集匹配**：用户方 ⊂ 经典方 → 标注"以XX方为底方，缺：{缺失药味}"
3. **超集匹配**：经典方 ⊂ 用户方 → 标注"以XX方加减，加：{新增药味}"
4. **模糊匹配**：Jaccard 相似度 ≥ 0.6 → 标注"类XX方化裁（置信度：XX%）"

示例：
- 用户输入「麻黄 桂枝 杏仁 甘草」→ 精确匹配"麻黄汤"
- 用户输入「麻黄 桂枝 杏仁 甘草 石膏 生姜 大枣」→ 超集匹配"麻黄汤"加石膏/生姜/大枣 → 即"大青龙汤"

#### 君臣佐使推断规则

- **君药**：剂量最大，或针对主证的药味
- **臣药**：剂量次之，增强君药功效或治疗兼证
- **佐药**：剂量较小，制约君臣毒性/烈性或治疗次要兼证
- **使药**：剂量最小，调和诸药或引经报使（典型使药：甘草）

#### 治法归类

21 类治法对应 formula.json 的 21 章：
解表 / 泻下 / 和解 / 清热 / 祛暑 / 温里 / 表里双解 / 补益 / 固涩 / 安神 / 开窍 / 理气 / 理血 / 治风 / 治燥 / 祛湿 / 祛痰 / 消食 / 驱虫 / 涌吐 / 治痈疡

### 1.5 炮制合理性层

#### 常见炮制品与治法匹配

| 炮制方法 | 效用变化 | 适配治法 |
|----------|----------|----------|
| 生品 | 偏寒/偏泻/偏散 | 清热/泻下/解表 |
| 炙品 | 偏温/偏补/偏缓 | 温里/补益/止咳 |
| 炒焦 | 增强健脾消食 | 消食/化积 |
| 煅制 | 收敛固涩 | 固涩/收湿 |
| 酒制 | 活血通络 | 活血/祛风 |
| 醋制 | 入肝止痛 | 理气/止痛 |
| 盐制 | 入肾下行 | 补肾/利水 |
| 蜜炙 | 润肺止咳 | 润肺/化痰 |
| 姜制 | 温中止呕 | 温中/止呕 |
| 法制 | 降低毒性 | 含毒性药时 |

#### 常见应炮制而未炮制的风险

- 半夏：生半夏毒性大，内服必须用炮制品（法半夏/姜半夏/清半夏）
- 附子：生附子有大毒，必须炮制后用
- 马钱子：生品禁用，必须炮制减毒
- 斑蝥：生品有大毒，必须米炒减毒

### 1.6 风险综合层

#### 常见风险模式

| 风险模式 | 级别 | 识别规则 |
|----------|------|----------|
| 苦寒伤胃 | 🟡 | 处方中苦寒药 ≥ 3 味 且 无护胃药（甘草/生姜/大枣/白术） |
| 温燥伤阴 | 🟡 | 温燥药 ≥ 3 味 且 无养阴药 |
| 破气伤正 | 🟡 | 破气药（枳实/青皮/厚朴等）≥ 2 味 且 无补气药 |
| 活血出血风险 | 🔴 | 活血药 ≥ 3 味 且 患者可能有出血倾向 |
| 长期肝肾负担 | 🟡 | 含毒性药材 + 天南星/关木通/马兜铃等 |
| 中西药相互作用 | 🟡 | 从 herbs.json 的 `western_interactions` 字段查询 |

**格式**：`[方剂溯源] + [核心功效] + [关键特征/风险提示]`
